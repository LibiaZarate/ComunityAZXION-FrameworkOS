# SOP · Confianza y evidencia

La confianza no es un porcentaje producido por intuición del modelo. Es una lectura separada de las condiciones que sostienen o limitan un hallazgo.

## Dimensiones

| Dimensión | Pregunta |
|---|---|
| Cobertura | ¿Qué proporción del universo esperado está instrumentada? |
| Completitud | ¿Están presentes los campos necesarios para la fórmula? |
| Actualidad | ¿La latencia permite tomar esta decisión ahora? |
| Consistencia | ¿Las fuentes coinciden o existen contradicciones? |
| Unicidad | ¿Duplicados o reintentos inflan el resultado? |
| Linaje | ¿Puede reconstruirse de dónde salió cada dato? |
| Muestra | ¿Hay observaciones suficientes para la decisión propuesta? |
| Sesgo | ¿La selección excluye casos relevantes? |
| Confusores | ¿Cambiaron audiencia, presupuesto, oferta, vendedor u otra variable? |
| Magnitud | ¿El efecto observado es operacionalmente relevante? |

## Salida obligatoria

Todo diagnóstico declara:

- nivel cualitativo: alto, medio, bajo o no evaluable;
- evidencia que lo sostiene;
- dimensiones que lo limitan;
- explicaciones alternativas;
- acción permitida por ese nivel.

Un nivel bajo puede justificar instrumentar o extender una prueba; no justifica desplegar autónomamente una decisión sensible.

## Regla causal

- **Hecho:** proviene de una fuente autoritativa verificable.
- **Inferencia:** interpretación derivada y explicada.
- **Hipótesis:** explicación que todavía debe probarse.
- **Causalidad probable:** requiere diseño comparable y control razonable de confusores.
- **No medible:** faltan definición, fuente, cobertura o evento.

El sistema nunca convierte correlación en causalidad por la seguridad con la que redacta.
