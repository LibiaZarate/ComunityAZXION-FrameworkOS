# Verticales de industria

Este repositorio contiene un núcleo comercial genérico. Añade una carpeta de industria cuando exista evidencia repetida suficiente para describir reglas comunes.

Un vertical puede incluir procesos, vocabulario, métricas y excepciones válidos para esa industria. No debe contener nombres, precios, datos, credenciales ni decisiones exclusivas de un negocio. Marca lo no confirmado como hipótesis.

La instancia privada de cada negocio permanece separada. Promueve solo aprendizajes generalizables y revisados al framework o a un vertical.
