# Dominio comercial adaptativo

El dominio comercial conecta marketing, conversaciones, ventas, producto y resultado. No replica el organigrama: modela cómo fluye el valor entre áreas.

```text
Atención
→ touchpoint
→ conversación
→ oportunidad
→ calificación
→ handoff
→ seguimiento
→ propuesta
→ revenue
→ delivery
→ resultado
→ retención, expansión o referido
```

## Capacidades mínimas

1. **Identidad multicanal:** una persona u organización puede tener múltiples identidades.
2. **Atribución:** el origen viaja hasta el resultado con su nivel de certeza.
3. **Ledger de eventos:** cada transición relevante se inserta; no se reconstruye desde el estado actual.
4. **Contexto comercial:** intención, necesidad, objeción, prioridad, autoridad y siguiente paso.
5. **Responsabilidad:** cada oportunidad activa tiene dueño y próxima fecha.
6. **Observabilidad:** volumen, conversión, latencia, valor, cobertura y excepciones.
7. **Decisiones:** cada recomendación declara evidencia, confianza, dueño y autoridad.
8. **Experimentación:** los cambios son versionados, controlados y reversibles.

## Dominios conectados

### Marketing

Campaña, audiencia, anuncio, creativo, contenido, inversión y touchpoints. Su resultado no termina en conversaciones: llega hasta pipeline y revenue cuando la instrumentación lo permite.

### Ventas

Oportunidad, etapa, actividad, handoff, seguimiento, cita, propuesta, pérdida y revenue. El pipeline es una proyección del ledger, no la fuente histórica.

### Producto y delivery

Oferta comprada, promesa, onboarding, hito, aceptación, adopción y resultado. Cierra el loop para que ventas y marketing aprendan de clientes reales.

### Customer success

Retención, expansión, recomendación y evidencia. Solo se activa cuando forma parte de la restricción o del alcance.

## Regla de alcance

Una instancia no instala todos los módulos. Activa únicamente los necesarios para observar la restricción inicial, intervenirla y medir el resultado sin romper el sistema aguas abajo.
