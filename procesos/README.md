# procesos/

**Naturaleza: OPERACIÓN** — se ejecuta.

Una carpeta por cada área de tu negocio (como tu organigrama): `ventas/`, `marketing/`, `producto/`, `soporte/`, etc.

Cada proceso lleva **dos archivos** (ver [`../estructura/historico-framework-pattern.md`](../estructura/historico-framework-pattern.md)):
- `historico.md` — qué pasó (DATA, se acumula).
- `framework.md` — la estrategia vigente (CONTEXTO, se lee).

## Ejemplo
```
procesos/
├── ventas/
│   ├── historico.md
│   └── framework.md
└── marketing/
    ├── historico.md
    └── framework.md
```
